# syncped

syncped offers a full featured source code text editor.

## Requirements

- [cmake](http://www.cmake.org/)
- [wex lib](https://github.com/antonvw/wex/)
- a `c++26` standard supporting compiler

## Building

```bash
git clone https://gitlab.kitware.com/antonvw/syncped.git
```

or

```bash
git clone https://github.com/antonvw/syncped-app.git
```

### for Linux or osx

`wex-build-gen.sh`

### for Visual Studio

`wex-build-gen.ps1`
